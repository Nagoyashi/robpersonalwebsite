# v0.2.0 — Solo studio homepage + live fleet

The site is rebuilt as a one-person software-studio homepage, with a live fleet
of products wired to GitHub data at build time.

## Highlights

- **New identity & homepage.** Operator headline ("I design, build, and run
  software products. Solo."), a single-scroll layout, and the refined dark +
  electric-cyan / neon-magenta terminal aesthetic — made accessible and robust.
- **Live fleet (centerpiece).** A flagship card plus the rest of the fleet, each
  showing name, one-line description, status pill, version badge, and
  last-shipped — links go to the deployed site (repo link only where public).
- **Build-time GitHub data layer.** `src/config/products.ts` is the single
  source of truth; `src/lib/github.ts` enriches it with live versions, releases,
  and open milestones at build time, with graceful fallback so the fleet always
  renders. No client-side fetching, no token in the bundle.
- **New pages.** `/now` (from `now.md`), `/uses`, and `/log` (full release log).
- **Now strip** combines a hand-written headline with the auto-derived
  "currently shipping" line from open GitHub milestones.

## Under the hood

- Migrated to **Astro** (zero JS by default); content pages are Markdown.
- **Deploy** moves to GitHub Pages via Actions, with a **daily rebuild** to keep
  fleet data fresh; CI `validate` now runs `astro check` + `astro build`.
- Optional read-only **GitHub App** enables live data for private repos
  (build-only secret); without it, private repos show config fallbacks.

## Polish

- Loads the fonts actually used (JetBrains Mono + Poppins); fixed dead links;
  real footer links; favicon, meta description, and OpenGraph/Twitter tags;
  accessibility pass (skip link, focus states, reduced-motion, landmarks).
